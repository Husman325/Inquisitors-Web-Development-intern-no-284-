# INQUISITORS Society Website

## Project Overview
This project is a multi-page website developed for the **INQUISITORS AI & Quiz Society** using **HTML5 only**. It was created as part of a web development assignment with the objective of building a clean, semantic, and well-structured website without using CSS, JavaScript, or any external frameworks.

The website introduces the society, highlights its services, showcases major events, and provides contact information through an organized and user-friendly layout.

## Website Pages
- Home
- About
- Services
- Events
The Contact section is available on the Home page and can be accessed directly from the navigation menu.
## Features
- HTML5 semantic structure
- Multi-page navigation
- Responsive HTML layout using semantic elements
- Society introduction
- Services overview
- Event showcase
- Contact section
- Image integration
- Tables, lists, and forms
- Clean and readable code

## Technologies Used

 HTML5
No CSS, JavaScript, Bootstrap, or other frameworks were used in this project.
