Inquisitors Society website (3D)

HOW TO RUN IN VS CODE
1. Unzip this folder and open it in VS Code (File > Open Folder).
2. Install the "Live Server" extension.
3. Right-click index.html > "Open with Live Server".
   (Double-clicking index.html also works.)

FILES
index.html            page content
assets/css/style.css  all styling and colors (edit the :root variables at the top)
assets/js/main.js     event data, filters, count-up and the 3D scene
assets/js/three.min.js  three.js r128 (bundled, works offline)

The Space Grotesk font loads from Google Fonts when online; a system font is used offline.
To edit events, change the E array in assets/js/main.js.
